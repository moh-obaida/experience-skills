# Branded States, Sparse and Dense Identity

Identity that only exists in the hero is not identity. This reference covers the surfaces where
brands usually disappear: states, sparse pages, dense pages, and the small vocabulary of spacing,
edges, and interaction that carries identity everywhere.

## Branded states

| State | Where identity belongs | Keep plain |
|---|---|---|
| Empty | One proportionate motif fragment or character pose; product voice in one sentence | The action and the explanation |
| Loading | Skeletons in the product's shapes; a brief motif animation for long waits | Progress facts (stage, time) |
| Error | Voice (calm, specific) and one visual cue; mascot only if its tone fits the severity | The cause, recovery action, reference ID |
| Success | The motion signature and color role for resolution; celebration proportional to the achievement | What happened and the next action |
| Offline / degraded | Consistent banner style | What still works |

Precedent: Grafana's mascot not-found state (GF2) is branded and actionable; Spotify's empty library
states (SPd1) are plain and actionable. Both are right for their products.

## Identity under sparse content

- Put the carrier in the environment (field color, pattern, type scale), not in more elements.
- Scale the typographic voice up on sparse pages; it fills space with meaning.
- Use the product's object (a card, a board, a composer) as the focal element.
- Never add filler to "show the brand."

## Identity under dense content

- Dense surfaces carry identity through type (a distinctive UI face or numerals), one signature
  color role (selection, focus, or brand accent), iconography style, and interaction feel.
- Keep motifs out of data regions; use them in headers, empty panels, and transitions.
- Precedent: GitHub (GH1–GH4) and Hacker News (HN1, HN2) are recognizable through structure alone.

## The small vocabulary

| Carrier | Identity decision |
|---|---|
| Spacing personality | Tight and efficient vs generous and calm; consistent everywhere |
| Density personality | The default rows per screen; offer compact only if the brand is expert |
| Edge treatment | Sharp, soft, chamfered, hand-drawn; derived from the product's shapes |
| Product primitives | The recurring objects (tokens, tiles, cards, bubbles) drawn the same way everywhere |
| Interaction vocabulary | How things respond: instant and precise, springy, physical |
| Motion identity | One motion language (see the motion languages module) |
| Icon system | One style; custom icons where the product's objects differ from generic ones |

## Checks

1. Logo test on an empty state, an error state, a dense list, and a settings page.
2. The branded element never reduces the legibility or contrast of the task.
3. Celebration intensity matches the achievement (saving a setting is not a celebration).
