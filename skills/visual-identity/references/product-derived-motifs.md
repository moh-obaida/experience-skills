# Product-Derived Motifs

A motif is a recurring visual element that belongs to the product. Good motifs are found in
the product, not imported from a trend.

## Where to find motifs

| Source | Questions | Examples |
|---|---|---|
| Core mechanic | What does the user do most? | Stacking blocks → stepped layouts; connecting dots → line motifs |
| Content artifacts | What objects does the product handle? | Tickets, cards, receipts, maps, charts, notes |
| Domain tools | What tools does the real-world domain use? | Rulers, grids, ledgers, stamps, tape, chalk |
| Game or board elements | Tiles, tokens, boards, cards, dice | Hex tiles, token circles |
| Data shapes | The shape of the data | Timelines, trees, networks, heatmaps |
| Cultural context | Where the product lives | Regional patterns, local typography traditions (with care and respect) |
| Name and story | The product's name or origin | A literal or abstract mark echoed in patterns |

## Turning a source into a motif

1. Abstract it: simplify to shape, line, or pattern.
2. Test at multiple scales: background field (large, low contrast), accent (small, high contrast).
3. Define where it appears: 3–5 recurring placements (environment backgrounds, headers,
   empty states, loading, results).
4. Define where it never appears: inside controls, over body text, in dense data regions.

## Intensity levels

- **Ambient:** low-contrast background pattern; environment only.
- **Structural:** corner cutouts, dividers, frames borrow the motif's geometry.
- **Featured:** motif at full strength in key moments (results, celebrations, hero).

Most surfaces should use ambient or structural. Featured is for moments.

## Anti-patterns

- Generic abstract blobs and waves (not derived from anything)
- Motifs so busy they reduce text contrast
- Motifs applied to every surface at the same intensity
- Cultural motifs used superficially or out of context
