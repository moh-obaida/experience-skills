# Identity Audit: The Logo Test and Identity Carriers

Load first: measure how recognizable the product is and which carriers exist.

Sections: The Recognition (Logo-Removal) Test · Identity Without Logo

## The Recognition (Logo-Removal) Test

A practical test for identity.

### Procedure

1. Choose 3–5 representative surfaces: a FOCUSED one (sign-in or join), an OPERATIONAL one
   (home, list), a dense one, an empty state, and a key moment (results, confirmation).
2. Hide the logo, product name, and any text that names the product.
3. Ask: could this be a different product? Which one? What still identifies it?
4. If possible, place the screens next to screenshots of competitors (or generic templates) and
   compare.

### Rating (descriptive, not numeric)

| Result | Meaning |
|---|---|
| Recognizable | A familiar user would identify it; several carriers visible |
| Partially | One carrier (usually color) identifies it; weak on dense or sparse pages |
| Generic | Indistinguishable from a template or competitor |

### Interpreting results

- **Generic on all surfaces:** no identity system; start with a brief (see `references/deriving-identity.md`).
- **Recognizable only on marketing:** identity is hero-deep; extend carriers to product surfaces.
- **Recognizable only by color:** add a second and third carrier (type, motif, shape).
- **Recognizable but noisy:** too many carriers at full volume; reduce.

### When "generic" is acceptable

A public-service form or a utility may deliberately look plain. Then the test becomes: is it
recognizably *consistent* (same voice, type, spacing, component behavior across the service)?
Plainness done consistently is an identity.

### Reporting

```
Logo test (5 surfaces, logo hidden):
- Join: generic (centered card, default font, no environment)
- Lobby: partially (team colors only)
- Host console: generic
- Results: recognizable (podium motif, team colors, display type)
- Empty library: generic
Carriers present: team color roles, podium motif (results only)
Missing: environment on focused pages; type voice
```

## Identity Without Logo

A logo identifies; it does not create identity. The product should remain recognizable when
the logo and name are hidden.

### Identity carriers

| Carrier | What it is | Strong when | Weak when |
|---|---|---|---|
| Typography | Typeface choice and how it is used | Distinct display face, confident scale, consistent usage | One neutral sans at three sizes |
| Color roles | What each color means | One or two signature colors with clear jobs | Palette of equally used accents |
| Shape language | Corners, strokes, geometry | Derived from the domain (hex board, paper cut, rounded soft for kids) | Maximum radius on everything |
| Motifs | Recurring product-derived elements | Pattern or mark that appears in a few meaningful places | Random blobs |
| Surface | Flat, layered, textured, printed, glowing | Consistent material logic | Glass here, neumorphism there |
| Imagery | Photography, illustration, 3D, video | Art-directed, consistent style | Stock and mixed styles |
| Motion | How things arrive and resolve | A signature for key events | Default fades |
| Voice | Copy tone and terminology | Specific, consistent, human | Generic marketing phrases |
| Interaction feel | Speed, keyboard, responsiveness | Consistent, fast, precise | Inconsistent behavior |
| Spatial rhythm | Density, margins, grid | Recognizable proportions | Framework defaults |

### Choosing carriers

Pick 2–4 that suit the product and archetype:

- **Game / playful education:** motif + color roles + shape language + motion.
- **Editorial / content:** typography + imagery + spatial rhythm.
- **Developer tool:** typography + color roles + interaction feel + voice.
- **Commerce / lifestyle:** imagery + typography + surface.
- **Productivity:** interaction feel + color roles + spatial rhythm + one quiet motif.
- **Public service:** voice + typography + consistency (plainness as identity).

### Applying carriers across surfaces

| Surface | Where identity lives |
|---|---|
| Landing / marketing | All carriers at higher intensity |
| Join / sign-in (FOCUSED) | Environment (motif, color field, imagery); controls plain |
| Operational home | Type, color roles, rhythm; motif in headers or empty states |
| Dense tools | Type, color roles, interaction feel; minimal ornament |
| Empty states | A single motif or illustration element, proportionate |
| Results / celebrations | Motion signature, color, motif at full strength |
| Errors | Voice; calm consistent styling |
