# Empty State Copy

## Structure

1. **Headline:** the specific state, plainly. "No quizzes yet." "No results for 'photosynthsis'."
   "You're all caught up."
2. **One supporting sentence (optional):** what goes here or why it is empty. "Quizzes you create or
   import will appear here."
3. **Action label:** a specific verb. "Create a quiz," "Clear filters," "Request access."

## Good vs weak

| Weak | Better |
|---|---|
| "Nothing to see here!" | "No games hosted yet." |
| "Oops! No data." | "No results for 'photosynthsis'. Try 'photosynthesis'." |
| "Get started by clicking the button below to create your very first amazing project!" | "Create a project" |
| "No items" (filtered) | "No quizzes match these filters. Clear filters" |
| "Access denied" | "This class is limited to its teachers. Ask Sam Lee for access." |

## Tone

- Specific beats cute. Light personality is fine when it does not replace information.
- Celebrate genuine completion states ("All caught up") briefly.
- Avoid blame, avoid exclamation overload, avoid marketing.

## Localization

Keep strings short and free of idioms and wordplay; they are translated and must fit in small
spaces.
