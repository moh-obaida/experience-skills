# Full Product Phase Map

Each phase produces an artifact the next phase consumes. Reading a skill name aloud is not invoking it: open the skill, follow its relevant checkpoints, and record the decision.

| Phase | Skills | Required handoff | Stop gate |
|---|---|---|---|
| 0 inspect | experience-architect | repository, routes, user jobs, current evidence, protected strengths | current surface rendered when runnable |
| 1 understand | product-friction | friction ledger ranked by frequency and impact | primary/secondary jobs known |
| 2 simplify | workflow-compression, interaction-design | before/after flow, control and safety decisions | meaningful human decisions preserved |
| 3 identity | visual-identity | niche profile, three system candidates, tradeoffs, selection | selected system suits product and constraints |
| 4 composition | composition-repair | route-specific focal points and viewport budgets | main tasks visible and sequenced |
| 5 states | state-design, empty-state-design | state matrix, absence reasons, recovery | no fabricated content or generic error |
| 6 build | implementation using prior artifacts | working routes and reusable tokens/components | chosen system appears in code |
| 7 motion | motion-design | event-to-motion map, including decisions for no motion | reduced motion and interruption covered |
| 8 responsive | responsive-validation | viewport/state matrix and fixes | no known P0/P1 overflow or clipping |
| 9 anti-slop | anti-slop-ui | unjustified patterns removed or defended | every treatment has a job |
| 10 de-generate | anti-ai-slop | identity ledger, protected list, generated-looking areas reconstructed | twenty-sites and weirdness tests answered |
| 11 forensic | interface-forensics | rendered findings, source trace, repairs | P0/P1 fixed or explicitly open |
| 12 challenge | critical-review | verdict against original and simplest alternative | weak decisions revised or reverted |
| 13 repair | relevant specialists | fixes for review and forensic findings | no known P0/P1 or S0/S1 open without reason |
| 14 verify | all relevant skills as needed | final test and render evidence | no unsupported completion claim |

The sequence can loop: a forensic issue may return to composition or state design. Preserve the earlier decision artifact and revise it, rather than silently restarting. A no-change result is valid when the specialist inspected its concern and explains why existing behavior serves the job. If no renderer is installed or available, try the installed measurement/render scripts with Playwright. Respect an explicit browser security denial; do not use another route around it. An unavailable renderer is a verification gap, not a license to call source inspection a visual pass.
