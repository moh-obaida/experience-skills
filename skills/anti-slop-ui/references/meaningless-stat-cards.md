# Meaningless Stat Cards

## Recognize it
Tiles showing "Total Projects: 3," "Active Users: 1," "Storage: 0.2%," "+12% this week" (from 1 to
1.12), often on nearly empty accounts, with green arrows and sparklines.

## Why it is slop
- Numbers that do not change the user's next action
- Trends without context (compared to what? why?)
- On sparse accounts, zeros and ones that emphasize emptiness
- They fill space in screenshots and inform no one

## Test
For each number: What would the user do differently if it were higher or lower? If nothing, remove it.

## Repair
- Replace with actionable state ("2 quizzes need review")
- Or with the underlying items (the actual list)
- Keep a number only with context (target, comparison, explanation)
- On empty accounts, show next actions instead (empty-state-design)
