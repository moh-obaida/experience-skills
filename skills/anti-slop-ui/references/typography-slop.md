# Typography Slop

## Recognize it
- One neutral sans (often the framework default) at three similar sizes
- Gradient text on headlines
- Tiny uppercase letter-spaced gray "eyebrow" labels above every heading
- Oversized hero headline followed by small body, with nothing between
- Light weights on low-contrast backgrounds
- Centered multi-line paragraphs

## Why it is slop
Typography is the strongest identity carrier; defaults waste it. Eyebrows and gradient text are
decorative habits, not a system.

## Repair
- Define roles (display, UI, body, data) and a scale with clear steps.
- Choose a display face with character suited to the product, or use a neutral face with strong,
  deliberate scale and weight contrast.
- Use eyebrows only within a real typographic system (for example consistent section labels in
  long documents), not on every heading.
- Left-align (start-align) body text; keep measure readable.
- Check contrast for all weights.
