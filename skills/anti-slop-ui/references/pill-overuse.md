# Pill Overuse

## Recognize it
Fully rounded capsules for: status labels, categories, buttons, navigation items, section eyebrows
("✨ New"), metadata, and counts, often in pastel backgrounds.

## When pills are right
- Filters and filter chips (toggleable)
- Tags and tokens (removable, often with ×)
- Compact status in dense tables where color + text encode state
- Selected values in multi-select inputs

## Why overuse hurts
Pills become visual noise and lose their meaning. Users cannot tell which are interactive (filters)
and which are labels. Pastel pill soup also weakens hierarchy.

## Repair
- Keep pills for filters, tags, and tokens.
- Use plain text or small caps for metadata; use icons + text for status where pills clutter.
- Use regular button shapes for buttons (per the design system).
- Remove eyebrow pills above headings unless part of a deliberate system.
