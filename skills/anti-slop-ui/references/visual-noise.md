# Visual Noise

## Recognize it
Many treatments competing: multiple accent colors, gradients, shadows, borders, icons, badges,
pills, illustrations, and animations on one screen, each at similar intensity.

## Diagnose
- Squint: does anything stand out, or is it uniformly busy?
- Count distinct accent colors (more than two or three is suspicious outside data visualization).
- Count distinct container treatments.
- Count elements with motion on load.

## Repair
- Establish one focal point; lower everything else.
- Reduce the palette to roles (see visual-identity color roles).
- One grouping method per level (space, then rules, then containers).
- Remove decoration that fails the design-vs-decoration test.
- Keep richness that has meaning (imagery, motifs) and remove what competes with it.

Richness is not noise. A dense, richly art-directed page can be calm if hierarchy is clear.
