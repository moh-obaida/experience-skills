# Bento Everywhere

## Recognize it
An asymmetric grid of rounded tiles of mixed sizes, each with a heading, a line of copy, and an
illustration or mini-UI, used for any feature list.

## When a bento layout works
- Features genuinely differ in importance (size reflects it)
- Each tile shows something real (actual product UI, real data) rather than decorative art
- The product's visual world suits a modular grid

## Why overuse hurts
Tile sizes are arbitrary, so hierarchy is fake. The layout signals "trend," not content. On mobile,
bentos collapse into a long stack of similar cards.

## Repair
- Rank features; give the top one or two real depth (demo, walkthrough); list the rest compactly.
- If using a grid, make size encode importance and show real product.
- Consider narrative sections instead: one idea per section with a real example.
