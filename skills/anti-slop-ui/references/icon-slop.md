# Icon Slop

## Recognize it
- An icon beside every heading, list item, and feature, all from one generic set
- Icons in colored rounded squares on every feature card
- ✨ sparkles meaning "AI" everywhere
- Emoji used as a design system
- Icons whose meaning is unclear, with no label

## When icons help
- Common, unambiguous actions (search, close, settings, share) with accessible names
- Dense toolbars where space is scarce and tooltips/labels are available
- Disambiguating similar items (file types, statuses) consistently
- Wayfinding in navigation alongside labels

## Repair
- Remove icons that repeat the adjacent text.
- Keep icon + label for navigation and important actions.
- Use a consistent icon style tied to the shape language.
- Replace sparkles with a description of what the feature does.
