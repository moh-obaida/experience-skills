# Generic Copy

## Recognize it
- Verbs: unlock, elevate, supercharge, empower, revolutionize, transform, streamline, leverage
- Adverbs: seamlessly, effortlessly, instantly (unverified), intelligently
- Adjectives: powerful, cutting-edge, next-generation, all-in-one, robust, intuitive, delightful
- Phrases: "Everything you need to…," "Built for the future of…," "Take your X to the next level,"
  "Get started in seconds," "Your all-in-one platform"
- Feature names: "Smart Insights," "Powerful Analytics," "Seamless Integrations"

## Test
Could this sentence appear on a competitor's site unchanged? Does it contain a fact a user could
check?

## Repair
Write specific, checkable statements:

| Generic | Specific |
|---|---|
| "Supercharge your classroom engagement" | "Run a 10-minute quiz game from any saved lesson. Students join with a 6-digit code." |
| "Powerful analytics" | "See which questions most students missed, per class." |
| "Seamless integrations" | "Import rosters from Google Classroom and Clever." |
| "Get started in seconds" | "Paste a document; get a quiz draft to edit." |

Also: prefer the user's vocabulary; cut adjectives; use numbers only when true.

The scanner (`scripts/scan-slop.mjs`) flags common phrases in source strings.
