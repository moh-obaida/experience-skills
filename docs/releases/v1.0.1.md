# Experience Skills v1.0.1 — Unified Marketplace Distribution

**Release date:** 2026-10-08

Experience Skills v1.0.1 adds a second distribution format: a complete, MIT-licensed marketplace
ZIP with one master skill entry point. The standalone Skills CLI distribution and specialist
methods remain in place.

## What's included

- `Experience-Skills.zip`, with one root `SKILL.md` named `experience-skills`.
- All 15 existing specialists, converted to packaged `METHOD.md` entry points.
- Each specialist's existing references, scripts, assets, and generated `_shared` resources.
- The complete design-intelligence resources required by the canonical methods, conditionally
  loaded instead of placed in the master context by default.
- Selective routing, keeping `anti-slop-ui` review distinct from `anti-ai-slop` repair and
  preserving `experience-architect` and `use-all-skills` semantics.
- Deterministic ZIP generation, checksum manifest, extraction/resource validation, route coverage
  checks, and a machine-readable validation report.
- The existing MIT license and third-party notices.

The release changes distribution and validation tooling; it does not claim a redesign of the
underlying specialist methods. Both distributions remain free.

## Validation scope

Repository validation and extracted Skills CLI installation establish mechanical packaging and
resource integrity. They are not an agent-quality evaluation. No model-driven demonstration or
Agensi scanner acceptance is claimed unless separately verified after publication.
