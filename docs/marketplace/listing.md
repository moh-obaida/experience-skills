# Experience Skills

**Price:** Free
**License:** MIT

## Short description

A complete experience-design toolkit for AI coding agents, combining 15 specialized methods with design intelligence, workflow analysis, visual identity, responsive verification, and anti-AI-slop reasoning.

## Description

Experience Skills helps AI coding agents build and improve digital products that are distinctive,
usable, efficient, and coherent. One master entry point routes to a complete collection of 15
specialist methods and their local references, scripts, assets, and vendored design intelligence.
The methods support product experience architecture, visual identity and design direction,
composition and layout repair, workflow simplification, interaction design, state and error
experience, motion and feedback, responsive and RTL validation, anti-AI-slop evaluation and repair,
critical review, rendered interface forensics, and niche-specific context.

The router considers concerns broadly, activates specialists selectively, and grounds completion
claims in available evidence. It preserves the product's existing identity and mechanics, loads
references progressively, and asks for rendered verification when meaningful visual changes can be
run and inspected. No change is a valid result when evidence does not justify intervention.

The ZIP presents the complete collection behind one master skill named **Experience Skills**.
Design systems, niche candidates, palettes, and typography strategies are supporting reference
material, not additional independently registered skills. The original standalone skill folders
remain available through the repository's Skills CLI distribution.

All features and downloads are free. The bundle is MIT-licensed and includes its third-party
notices.
