# Spatial, Density, and Navigation Models

## Density models

| Model | Items per viewport (desktop) | Suits | Risk |
|---|---|---|---|
| Spacious | 1–3 focal objects | Focused, marketing, luxury, wellness | Dead space without a focal mass |
| Comfortable | 5–15 items | Most consumer apps, content | Generic if nothing else carries identity |
| Compact | 15–40 rows | Operational, admin, email | Small targets, low-contrast metadata |
| Dense | 40+ data points | Monitoring, trading, expert lists | Newcomer overload; zoom/reflow hard |

Choose by archetype and frequency; offer a density setting only for expert tools with mixed users.
Precedent spectrum: Brilliant (BR1) spacious, Coursera (CO1) comfortable-dense, GitHub (GH2) compact,
Hacker News (HN1) dense.

## Spatial models

| Model | Mental model | Suits |
|---|---|---|
| Page | Documents that scroll | Content, marketing |
| App shell | Fixed chrome, one scrolling pane | Operational apps |
| Split | Persistent panes (list/detail, canvas/inspector) | Triage, creation |
| Canvas | Infinite or bounded 2D space | Design, diagrams, maps, charts |
| Stack | Screens pushed and popped | Mobile flows |
| Stage | One focal region, environment around | Games, presentations, focused tasks |
| Room / spatial | 3D placement | XR, galleries |

## Navigation models

| Model | Use when | Watch for |
|---|---|---|
| Top bar | Few sections, marketing, content | Hidden overflow items on narrow screens |
| Sidebar | Many objects of a few types (apps) | Collapses to drawer on mobile |
| Bottom tabs | 3–5 top-level areas on phones | More than five; desktop misuse (NI2) |
| Search-first | Large catalogs, services | Search must understand users' words |
| Command palette | Many actions across a large app | Unnecessary in small products |
| Contextual (in-place) | Actions on the current object | Discoverability; provide menus too |
| Index / directory | Content-rich portals, docs | Needs good labels and grouping |
| Tabs with counts | Object views with status | Counts must be current (GH1) |

Pick the model by the number and frequency of destinations, then check it at mobile width, with a
keyboard, and with a screen reader.
