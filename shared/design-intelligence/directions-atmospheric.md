# Directions: Atmospheric Family

Directions built on mood, light, depth, and space.

---

## Atmospheric

**Philosophy:** mood first; light, texture, and color make a place.

| Aspect | Tendency |
|---|---|
| Suits | Games, music, travel, hospitality, brand experiences |
| Unsuitable | Forms, tools, dashboards |
| Composition | Environment-first focus, layered depth |
| Typography | Characterful display; restrained body |
| Surface & shape | Gradients as light, grain as material |
| Imagery | Moody photography or illustration |
| Palette | Cinematic or earthy families |
| Motion | Ambient, slow, pausable |
| Interaction | Conventional |
| Accessibility | Text over atmosphere needs scrims; ambient motion must respect reduced motion |

**Precedent:** Discord (DI1), Cloudflare glow (CF1), Google Flights illustration (G2). **Adapt:** one
atmosphere per product, not one per section.

## Cinematic

**Philosophy:** full-bleed imagery and sequencing; the page plays like a trailer.

| Aspect | Tendency |
|---|---|
| Suits | Film, launches, media, automotive, games |
| Unsuitable | Operational |
| Composition | Full-bleed narrative, immersive viewport |
| Typography | Large display over image |
| Surface & shape | Image is the surface |
| Imagery | Key art, video |
| Palette | Image-derived, dark |
| Motion | Cuts, reveals; must be skippable and reduced-motion safe |
| Interaction | Minimal; clear primary action |
| Accessibility | Autoplay video needs controls; captions |

**Precedent:** Xbox (XB1), Steam (ST2), PlayStation (PS1). **Fails when:** the message is deferred below
an image with no headline (XB1). **Adapt:** always state what this is in the first viewport.

## Layered depth

**Philosophy:** planes and overlap create hierarchy and wonder.

| Aspect | Tendency |
|---|---|
| Suits | Spatial products, portfolios, storytelling |
| Unsuitable | Dense tools |
| Composition | Foreground task over meaningful background, overlapping objects |
| Typography | Clear foreground type |
| Surface & shape | Shadows and blur with real layer meaning |
| Imagery | Cut-out objects, devices inside scenes |
| Palette | Depth through value, not only blur |
| Motion | Restrained parallax, reduced-motion alternative |
| Interaction | Foreground controls only |
| Accessibility | Parallax can cause discomfort |

**Precedent:** Discord devices in scene (DI3), Revolut card in photo (RV1). **Adapt:** depth must
express which plane is interactive.

## Spatial

**Philosophy:** rooms, distance, and placement; space itself is navigation.

| Aspect | Tendency |
|---|---|
| Suits | XR, maps, galleries, virtual events |
| Unsuitable | Forms |
| Composition | Map-centered, spatial canvases |
| Typography | Legible at distance |
| Surface & shape | Materials that respond to light |
| Imagery | 3D, maps |
| Palette | Environment-derived |
| Motion | Continuity of position is essential |
| Interaction | Direct manipulation; platform conventions |
| Accessibility | Non-spatial alternatives for every task |

**Adapt:** keep a list or search alternative for everything placed in space.
### Family checks

Responsive behavior removes depth before removing orientation. Accessibility and RTL require a
readable non-spatial path, logical focus order, reduced motion, and script-safe labels. AI failure:
turning every product into a dark cinematic hero. Customize the environment from a real product
object or place; keep controls familiar.
