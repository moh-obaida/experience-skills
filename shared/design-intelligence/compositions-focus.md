# Compositions: Focus Family

Surfaces with one dominant task or message.

---

## Centered focus

| Aspect | Guidance |
|---|---|
| Solves | One task where nothing else deserves attention |
| Archetypes | FOCUSED (sign-in, composer start, confirmation) |
| Content needs | The task itself; one line of orientation; something recognizable (type, mark, environment) |
| Hierarchy / focal | The control or message at the optical center (slightly above geometric center) |
| Viewport | Task visible without scrolling on the shortest supported height |
| Scroll | Usually none |
| Responsive | Full-width on phones with 16–24 px gutters; keep the action above the keyboard |
| RTL | Symmetric; mirror any directional icons |
| Touch | Large input and button; submit on Enter/Go |
| Accessibility | Focus the first field only if that is expected; visible labels |
| Sparse state | Is the sparse state; must not look unfinished |
| Dense state | n/a |
| Fails when | The page stays blank around a small card (centered-card syndrome) |
| Bad AI version | Logo + heading + card + button centered on flat grey, called "clean" |
| Precedent | ChatGPT (CG1, CG2), Claude (CL1, CL2), Kahoot (KH1) |

## Environment-first focus

| Aspect | Guidance |
|---|---|
| Solves | A focused task that is also a first impression (join a game, enter an event) |
| Archetypes | FOCUSED, EXPERIENTIAL |
| Content needs | Product-derived environment (pattern, illustration, imagery, color field) + standard control |
| Hierarchy / focal | Task panel is the focal point; environment is second and never competes on contrast |
| Viewport | Environment fills the viewport; task within the first viewport at all sizes |
| Scroll | None |
| Responsive | Environment scales/crops; the panel becomes full-width on phones |
| RTL | Mirror directional motifs; keep the panel centered or on the start side |
| Touch | Plain input with the right keyboard |
| Accessibility | Contrast of panel against environment; ambient motion pausable |
| Fails when | Environment is so busy the control loses contrast; assets are heavy |
| Bad AI version | Blank page plus six animated digit boxes |
| Precedent | Kahoot (KH1, KH2), Blooket (BK1), Google Flights (G2), Wise (W4) |

## Asymmetric split

| Aspect | Guidance |
|---|---|
| Solves | A task with context, proof, or imagery that deserves space |
| Archetypes | FOCUSED, marketing, sign-up |
| Content needs | Two genuinely different contents (task + context), not task + decoration |
| Hierarchy / focal | Task on the start side at about 40–60%; context on the other |
| Viewport | Both halves above the fold on desktop |
| Responsive | Stack at narrow widths with the task first |
| RTL | Mirror the split so the task stays on the start side |
| Fails when | One half is an abstract gradient with no information |
| Precedent | Webflow (WF1), Cursor (CU1) |

## Dominant object

| Aspect | Guidance |
|---|---|
| Solves | One object (a product, a number, a working widget, a mark) carries the message |
| Archetypes | Marketing, TRANSACTIONAL entry points |
| Content needs | An object worth the attention: product photo, live quote, composer, logo geometry |
| Hierarchy / focal | The object is the largest mass; headline relates to it |
| Viewport | Object and headline in the first viewport |
| Responsive | Object scales down but keeps priority over text |
| Fails when | The object is decorative (3D blob) or illegible (tilted, cropped screenshot) |
| Precedent | Wise calculator (W1), Vercel triangle (VC1), Framer composer (FR1), Apple models (AP3) |

## Poster statement

| Aspect | Guidance |
|---|---|
| Solves | One message must land before anything else |
| Archetypes | Campaigns, launches, manifestos |
| Content needs | A statement worth saying large |
| Hierarchy / focal | The statement; one action |
| Viewport | Statement fills the first viewport |
| Scroll | Below, the page becomes something usable |
| Responsive | Type scales with viewport (clamp) but stays readable |
| Fails when | Used on a task page; the statement is generic |
| Precedent | Patagonia (PA1), Cloudflare (CF1) |
