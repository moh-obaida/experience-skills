# Compositions: Content Family

---

## Content reading

| Aspect | Guidance |
|---|---|
| Solves | Articles, essays, help pages |
| Content needs | Title, lead, body, headings, images with captions |
| Hierarchy / focal | Title then text; measure 45–80 characters |
| Viewport | Title and first paragraph above the fold |
| Responsive | Same structure at every size; images full-width on phones |
| RTL | Full mirroring; check mixed-direction strings |
| Accessibility | Heading order, link visibility, line height |
| Dense state | Long articles need a table of contents |
| Fails when | Measure spans the full width; text is broken into cards |
| Precedent | Wikipedia (WPd1, WPm2), Our World in Data (OW1) |

## Documentation

| Aspect | Guidance |
|---|---|
| Solves | Reference navigated by people who jump and return |
| Content needs | Nav tree, on-page table of contents, consistent page anatomy, search |
| Hierarchy / focal | Title and "can I use this / what is this" first |
| Responsive | Nav collapses; on-page TOC moves above content |
| Accessibility | Keyboard navigation of trees; code blocks scroll horizontally |
| Fails when | Every page has a different structure |
| Precedent | MDN (MD1–MD4), Stripe Docs (SD1–SD4), Linear Docs (LD1, LD2) |

## Component playground

| Aspect | Guidance |
|---|---|
| Solves | Showing code and its live result together |
| Content needs | Real, runnable examples |
| Hierarchy / focal | The live preview and the code that makes it |
| Responsive | Stack preview above code on phones |
| Accessibility | Previews keyboard reachable; code copyable |
| Precedent | MDN "Try it" (MD3) |
