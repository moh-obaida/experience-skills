# Directions: Quiet Family

Directions that recede so the task can lead. Quiet is not empty: each still needs a recognizable
carrier (type, color role, rhythm, interaction feel).

---

## Restrained modern

**Philosophy:** neutral, precise, calm; identity through consistency and craft.

| Aspect | Tendency |
|---|---|
| Suits | Productivity, B2B, settings, collaboration tools |
| Unsuitable | Brands that need energy or spectacle |
| Composition | Sidebar workspaces, master-detail, compact operational |
| Typography | One neutral sans with clear role steps; tabular numerals |
| Surface & shape | Subtle surface value changes, small radii, few shadows |
| Imagery | Product UI, simple icons |
| Palette | Restrained neutral plus one action color and state colors |
| Motion | Short, functional |
| Interaction | Keyboard-friendly; inline editing |
| Accessibility | Watch low-contrast secondary text, a common failure in this direction |

**Fails when:** the neutrality becomes indistinguishable from every other product. **Slop risk:**
high; this is the model default. **Precedent:** GitHub (GH1–GH4), Linear docs (LD1). **Adapt:** pick
one carrier (type voice, a signature color role, interaction speed) and make it unmistakable.

## Minimal functional

**Philosophy:** only what the task needs, set with strong typography.

| Aspect | Tendency |
|---|---|
| Suits | Utilities, focused tools, calculators, single-purpose apps |
| Unsuitable | Experiential or brand-led products |
| Composition | Focused task region related deliberately to the viewport |
| Typography | Large, confident; very few sizes |
| Surface & shape | Flat |
| Imagery | None or one product-derived element |
| Palette | Neutral plus one accent |
| Motion | Feedback only |
| Interaction | Standard controls, fast |
| Accessibility | Easy to get right |

**Fails when:** minimal becomes empty (see fake minimalism). **Precedent:** Brilliant (BR1),
ChatGPT start (CG1). **Adapt:** the one remaining element must be the product.

## Soft minimal

**Philosophy:** gentle, rounded, pale; reassurance over efficiency.

| Aspect | Tendency |
|---|---|
| Suits | Wellness, family, home, journaling, onboarding for anxious users |
| Unsuitable | Data-heavy tools, trading, professional dashboards |
| Composition | Generous spacing, single-column flows |
| Typography | Rounded or humanist sans |
| Surface & shape | Large radii, soft surfaces |
| Imagery | Soft illustration, calm photography |
| Palette | Pastels with a stronger action color |
| Motion | Slow, soft easing |
| Interaction | Conventional; forgiving |
| Accessibility | Pastels frequently fail contrast; check every text/background pair |

**Fails when:** low contrast and large radii everywhere erase hierarchy. **Slop risk:** high (soft
cards and pastel gradients are model favorites). **Adapt:** keep softness in the environment; give
text and actions full contrast. **Precedent depth:** load `soft-minimal-products.md` and separate
the calm visual layer from the product's actual state model. SFM1, SFM2, SFM3, SFM4, SFM5, SFM6,
SFM7, SFM8, SFM9, SFM10, SFM11 show that wellness surfaces
still need taxonomy, entitlement, time, progression, trend, privacy, and gated-action signals. Use
soft minimal for reassurance, recovery, or repeated small actions—not for hiding complexity. On
mobile, preserve the next action and current state before decorative breathing room; in dense views,
use explicit grouping and a stronger action color rather than more pastel cards. Test contrast,
focus, reduced motion, dynamic text, RTL reading order, locked/unlocked states, and empty versus
unavailable content. If those states cannot remain obvious, choose utilitarian or calm-health
adaptation instead of decorating the ambiguity.

## Utilitarian

**Philosophy:** plain, fast, conventional; the software gets out of the way.

| Aspect | Tendency |
|---|---|
| Suits | Internal tools, admin, back-office, developer utilities |
| Unsuitable | Brand-led consumer marketing |
| Composition | Tables, forms, master-detail |
| Typography | System fonts |
| Surface & shape | Borders and rules |
| Imagery | None |
| Palette | Neutral with semantic state colors |
| Motion | None beyond feedback |
| Interaction | Keyboard, bulk actions, inline edit |
| Accessibility | Native controls help |

**Fails when:** plainness hides status or hierarchy. **Precedent:** GitHub Actions (GA1–GA3).
**Adapt:** invest in states and speed, not ornament.

## Calm health / wellness

**Philosophy:** reduce anxiety; clarity of what happens next; quiet color.

| Aspect | Tendency |
|---|---|
| Suits | Health utilities, mental health, care coordination |
| Unsuitable | Games, trading, high-energy retail |
| Composition | One task per screen when stakes are high; clear progress |
| Typography | Highly legible humanist sans; generous sizes |
| Surface & shape | Soft but not vague |
| Imagery | Real, diverse people; calm illustration |
| Palette | Calm blues/greens with strong text contrast; red reserved for true alerts |
| Motion | Minimal; never alarming |
| Interaction | Plain language, reversible steps, visible help |
| Accessibility | Priority; older users, low vision, cognitive load |

**Fails when:** calm becomes vague (unclear status, hidden next steps). **Adapt:** calm tone,
precise content.
### Family checks

Responsive behavior protects reading measure and the next action instead of shrinking type into
soft cards. Accessibility and RTL require high contrast, visible focus, large targets, and script
fallbacks. AI failure: neutral rounded cards with no product-specific carrier. Calm is a behavior and
content choice, not a lack of hierarchy.
