# Directions: Product and Content-Led Family

Directions where the product itself, or its content, is the visual.

---

## Product-first

**Philosophy:** show the product working; the UI or object is the image.

| Aspect | Tendency |
|---|---|
| Suits | Software products, devices, tools, financial calculators |
| Unsuitable | Content-first publications |
| Composition | Hero with real UI or live widget; workbench tours |
| Typography | Clear, confident; the product provides visual interest |
| Surface & shape | Frames that do not obscure the product |
| Imagery | Real, legible UI; product photography |
| Palette | From the product's own UI |
| Motion | Demonstrations of real flows |
| Interaction | Sometimes the hero is interactive (a real calculator, a real composer) |
| Accessibility | Screenshots need text alternatives; live widgets need labels |

**Precedent:** Wise (W1), ChatGPT (CG1), Framer (FR1), Cursor (CU1), Slack (SL2). **Adapt:** if the
product can be used in the hero, let it.

## Image-first

**Philosophy:** photography leads; type annotates.

| Aspect | Tendency |
|---|---|
| Suits | Travel, food, fashion, real estate, hospitality |
| Unsuitable | Text-heavy services, tools |
| Composition | Full-bleed or large images, captions, image grids |
| Typography | Restrained, legible over images with scrims |
| Imagery | Art-directed, consistent |
| Palette | Image-derived neutrals |
| Motion | Slow transitions |
| Accessibility | Alt text; text on images needs contrast |

**Precedent:** Airbnb (ABd1), Revolut (RV1), Monzo (MZ1). **Adapt:** decisions (price, dates) stay in
text, not in images.

## Commerce editorial

**Philosophy:** story around a buyable object; the story never blocks the purchase.

| Aspect | Tendency |
|---|---|
| Suits | Considered retail, design-led brands |
| Unsuitable | High-volume marketplaces |
| Composition | Product-first commerce with editorial breaks |
| Typography | Editorial display with clean UI type for prices and options |
| Imagery | Product and context photography |
| Palette | Warm editorial or luxury |
| Interaction | Size, variant, price, delivery, buy in one block |

**Precedent:** Aesop (AE1), Apple (AP2, AP3), Patagonia (PA1, PA2). **Adapt:** see the purchase-path example.

## Creator-tool

**Philosophy:** the canvas is the star; chrome recedes; power is close at hand.

| Aspect | Tendency |
|---|---|
| Suits | Design, video, audio, diagramming, writing tools |
| Unsuitable | Reading products |
| Composition | Canvas workspace with tool rails and inspectors |
| Typography | Compact UI type |
| Surface & shape | Dark or neutral chrome so content colors read true |
| Palette | Dark creator-tool family |
| Motion | Direct-manipulation feedback |
| Interaction | Keyboard shortcuts, contextual panels, undo everywhere |
| Accessibility | Icon-only tools need labels and keyboard paths |

**Precedent:** TradingView (TV1, TV2), Notion editing (NO1–NO3). **Adapt:** label or tooltip every tool.

## Diagrammatic

**Philosophy:** explain through systems, flows, and maps.

| Aspect | Tendency |
|---|---|
| Suits | Infrastructure, science, process products, education |
| Unsuitable | Emotional brands |
| Composition | Map/diagram composition, annotated sequences |
| Typography | Technical labels, readable annotations |
| Imagery | Diagrams as primary content |
| Palette | Technical or public-service families |
| Motion | Step-through of a process |
| Accessibility | Every diagram needs a text description |

**Adapt:** a diagram must explain something the text cannot do as fast.
**Precedent:** Excalidraw (EXC1–EXC4): the entire product is an unframed infinite canvas with one
floating, icon-only toolbar as the only chrome (EXC1). Measured computed styles show the custom
hand-drawn typeface (Excalifont) is reserved for exactly one moment — the empty-canvas welcome
heading that sets the product's tone — while every operable control (menu buttons, shortcut labels)
renders in plain system-font fallbacks, not the distinctive face (EXC2, EXC4): character lives in
one deliberate place, legibility and speed govern everything the user actually operates. Toolbar
icons show their keyboard shortcut letter directly on the icon for at-a-glance recall by repeat
users (EXC3). **Adapt:** EXC2/EXC4's principle — spend a distinctive typeface on the one moment that
sets tone, and keep every functional control in a plain, fast, legible system font — transfers to
any authoring tool (a tool for writing formal prose should not have a playful UI font; a tool for
sketching should not
have a rigid, corporate one).
### Family checks

Responsive behavior turns wide proof into a sequence or scrollable diagram while retaining the
claim and next action. Accessibility and RTL require text labels, logical order, and alternatives to
spatial-only meaning. AI failure: fake screenshots, diagrams, or metrics. Show the real product and
derive the visual carrier from the object users care about.
