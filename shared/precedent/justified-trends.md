# Precedent: When "AI-Looking" Techniques Are Right

Techniques that AI output often misuses (gradients, glows, centered layouts, dark themes, dense
screens, standard SaaS sequences) used with a clear reason. This module exists to prevent reverse
dogma. Observed 2026-09-24; IDs refer to `research/observations/`.

**Rule:** reject unjustified defaults, never techniques. For each entry, the reason is stated; if
your case has no comparable reason, the technique is probably a default.

---

### Gradient as long-standing signature — Stripe
`SR3` · https://stripe.com/ · rendered
- **Reason:** a consistent brand signature for years, placed in the environment; buttons are solid.

### Gradient as a creation world — Canva
`CA1 CA2` · https://www.canva.com/ · rendered
- **Reason:** signals play and creativity for a broad audience; used as field, not as UI fill.

### Glow and grid texture — Cloudflare
`CF1` · https://www.cloudflare.com/ · rendered
- **Reason:** a distinctive brand color field with a network-like texture; one action.

### Glowing input — Framer
`FR1` · https://www.framer.com/ · rendered
- **Reason:** the glow marks the product's own input as the centerpiece.

### Starfield and floating objects — Discord
`DI1` · https://discord.com/ · rendered
- **Reason:** a community-for-gamers world; the audience expects play.

### Centered layout — ChatGPT, Kahoot, Claude
`CG2 KH1 CL2` · rendered
- **Reason:** the centered element is the entire task (ChatGPT), framed by a strong environment
  (Kahoot), or carried by distinctive type (Claude).

### Dark environment — Steam, Spotify
`ST1 SPd2` · rendered
- **Reason:** artwork and media read best on dark; the content provides color.

### Extreme density — Hacker News, GitHub Actions
`HN1 GA1` · rendered
- **Reason:** expert, frequent scanning; every element is data.

### The standard SaaS sequence — Slack
`SL1` · https://slack.com/ · rendered
- **Reason:** a familiar structure executed with real UI and one action color; familiarity helps
  buyers compare. A template is fine when its parts are real and specific.

### Tilted product screenshot — Datadog
`DD1` · https://www.datadoghq.com/ · rendered
- **Reason:** the content (real dense dashboards) carries the message; the tilt is secondary.
- **Caution:** the same tilt on a sparse, fake screenshot is slop.

### Pill-shaped word treatment — Notion
`NT1` · https://www.notion.com/ · rendered
- **Reason:** mirrors the product's own inline chips (a product-derived shape); used once.

---

## Summary rules

1. A technique is justified by one of: long-standing brand signature, audience expectation, content
   that needs it, or a product-derived shape. Name which.
2. Justified techniques appear in the environment or once, not on every control.
3. The same technique with fake or sparse content is a default, not a decision.
