# Product Archetypes

Page archetypes describe a *surface*. Product archetypes describe the *whole product* and set the
defaults for its surfaces. A product usually has one primary archetype and borrows others for
specific surfaces.

| Product archetype | Density | Hierarchy priority | Visual intensity | Interaction model | Motion | Empty-state approach | Responsive focus |
|---|---|---|---|---|---|---|---|
| Focused task | Low | The task | Environment medium–high, control plain | One control, one action | Feedback only | Is the state | Short heights, keyboard |
| Operational dashboard | Medium–high | What needs action | Low–medium | Scoped actions, bulk, inline | Change highlights | Real next actions | Laptop heights |
| Experiential | Varies | Atmosphere and focal drama | High | Direct, playful, simple controls | Rich, event-driven | Keeps the world alive | Projector, phones |
| Editorial / content | Medium | Reading order | Medium, typographic | Links, TOC | Minimal | Related content | Measure at all widths |
| Data-heavy | High | Change and exceptions | Low | Filters, drill-down | Change highlights | Explain data arrival | Wide screens, zoom |
| Transactional | Low–medium | Consequence and commit | Low at commit | Preview, commit, undo | Resolution marks | Explain prerequisites | Keyboard and mobile forms |
| Discovery | High | Scannability, decision data | Medium–high around content | Search, filter, compare | Light | Suggestions | Grid reflow |
| Creation | High in tools | Canvas | Low in chrome | Direct manipulation, shortcuts | Manipulation feedback | Templates | Tablet split view |
| Live control | Medium | Current state | Medium | Scoped, large targets, undo | State transitions | Waiting states | Glanceability |
| Communication | Medium | Unread and active conversation | Low–medium | Compose, reply, react | Arrival of messages | Starter prompts | Keyboard overlap |
| Marketplace | High | Search and trust signals | Medium | Search, filter, compare, message | Light | Search-empty recovery | Mobile-first |
| Commerce | Medium | Product, price, buy | Medium–high around, low at buy | Variant, cart, checkout | Add-to-cart transfer | Empty cart continuation | Mobile product page |
| Public service | Low–medium | Task completion | Low (clarity as identity) | Question pages, error summaries | None | Plain explanation | Assistive tech, low-end devices |
| Educational | Medium | The lesson content | Medium, playful where appropriate | Practice, feedback, progress | Feedback events | Next lesson | Tablets, shared screens |
| Entertainment / media | Medium–high | Content artwork | High | Browse, play, queue | Transitions, playback | Recommendations | TV and phones |
| Game | Varies | The play surface and state | High | Controller/touch/keyboard parity | Event-rich | Lobby states | Many input types |
| Developer tool | High | Accuracy, speed | Low–medium | Keyboard, copy, CLI parity | Minimal | Quick-start commands | Wide and narrow terminals |
| Monitoring | High | Alerts and anomalies | Low | Acknowledge, drill-down | Change highlights | "All clear" state | Wall displays, phones on call |
| Finance | Medium | Balances, pending vs completed | Low–medium | Review then commit | Resolution | Explain no activity | Mobile first |
| Healthcare utility | Low–medium | Next step, safety | Low, calm | Plain forms, reminders | Minimal | Reassuring guidance | Accessibility, older users |
| Productivity | Medium | The user's work | Low–medium | Inline edit, shortcuts | Short | Continue work | Laptops |
| Social | Medium–high | Feed and people | Medium | Post, react, follow | Arrival, reactions | Suggested people | Phones |
| Documentation | Medium | Findability | Low–medium | Search, TOC, path selection | None | Search suggestions | Code blocks on phones |
| CLI | Output-dependent | Resolved plan, result, next command | Terminal colors only | Flags, prompts only when interactive | Progress only | Help text | 80 columns, no color |
| Desktop native | Medium–high | Workspace | Platform-consistent | Menus, shortcuts, multi-window | Platform motion | Onboarding templates | Window sizes, scaling |
| Mobile native | Medium | Thumb-reach actions | Platform-consistent | Gestures with visible alternatives | Platform motion | Friendly starters | Safe areas, text size |

Use this table to set defaults, then adjust for the specific product and audience. When a surface
belongs to a different archetype than the product (a finance app's marketing page), use the
surface's archetype for that surface.
