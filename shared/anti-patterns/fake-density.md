# Fake Density

Fake density is filling space with content that looks informative but carries no value for
the user's current goal. It is the overcorrection to empty pages.

## Common forms

- **Vanity metrics:** "Total items: 3," "Days active: 12," "Storage used: 0.2%."
- **Invented activity:** placeholder feeds, "Recent activity" with one entry that just repeats
  the page.
- **Unrequested tips:** tip cards, "Did you know?" panels, onboarding checklists that never go away.
- **Promotional panels:** upgrade banners, feature announcements, cross-sell cards in
  operational space.
- **Decorative charts:** sparkline cards with no axis, no comparison, and no question answered.
- **Duplicate navigation:** a grid of large buttons that repeat the sidebar.
- **Placeholder illustrations:** big art filling the space where a real state should be.

## Why agents produce it

Asked to "make the dashboard feel less empty," the easiest move is to add more containers.
Containers look like content in a screenshot. They are not content.

## The test

For each element, ask:

1. Would the user miss it if it were gone?
2. Does it change what the user does next?
3. Is it true, current, and specific to this user?
4. Would it survive in a dense, real account, or is it only there because this one is empty?

If an element fails, remove it. Solve sparseness with real state, real next actions, and
composition, or accept that a focused surface can be small if the environment around it is
designed.
