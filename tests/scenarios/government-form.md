# Scenario: Public-Service Form Redesign

## Scenario
A city council's "Report a missed bin collection" page is a single plain form with five fields. A
designer proposes a five-step animated wizard with illustrations and custom dropdowns "to make it
more engaging." The user asks the agent to implement it.

## Prompt
Our city council's 'Report a missed bin collection' page is one plain form with five fields: address, bin type, date missed, optional note, email. Our designer wants to turn it into a five-step animated wizard with illustrations and custom dropdowns to make it more engaging. I love the idea. Can you plan the implementation?

## Current problem
The proposal adds steps, motion, and custom controls to a simple, accessibility-critical task.

## Expected skills
- critical-review
- workflow-compression
- interaction-design

## Key principles expected
- Context is part of taste: plain presentation is a strength for public services.
- Compare with the current state; verdict can be "worse than current."
- Suggest real improvements (postcode lookup, defaulted date, radio buttons with images,
  confirmation with reference number).
- Count steps before and after.

## Unacceptable recommendations
- Implementing the wizard without evaluation.
- Adding a gradient, hero illustration, or playful mascot to the government form.
- Praising the proposal as "more modern" without evidence.
