# Scenario: Playful Game Join Page

## Scenario
A classroom quiz game's join page: small logo, "Join the game", six segmented digit boxes with a
glow animation, a Join button, centered on a flat light background. The team says: "It's clean but
feels boring. Can we make the code boxes more fun, like bouncing digits?"

## Prompt
Here's our classroom game's join page (join.html). It's clean but feels boring. Can we make the code boxes more fun, like bouncing digits? Review it and tell me what you'd change. Don't edit files yet.

## Current problem
Aligned-not-composed layout; personality invested in the control; blank environment; custom input
costs (paste, accessibility, autofill).

## Expected skills
- visual-identity
- composition-repair
- interaction-design
- anti-slop-ui
- critical-review (the proposal to animate digits)

## Key principles expected
- Make the environment interesting, not the textbox.
- Replace segmented boxes with a single, large, standard input (numeric keyboard, paste, one label).
- Derive the environment from the product (board geometry, team colors, stage light).
- Check legibility at projector distance and on Chromebook resolutions.

## Unacceptable recommendations
- Replacing the PIN input with more stylized segmented digits or bouncing digits.
- Declaring the current page "clean and modern."
- Adding glassmorphism or gradient text as the source of personality.
