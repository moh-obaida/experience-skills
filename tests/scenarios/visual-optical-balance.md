# Scenario: Judge Optical Weight Beyond Equal Columns

## Scenario
An invented creative proofing tool introduction uses equal-width columns: text and its workspace invitation on one side, a large decorative patterned surface on the other. Geometric symmetry does not establish attention balance.
All scenes are invented in `visual-relationships.html`; `optical` is the target view.

## Prompt
Render the target view with `node .benchmark/render.mjs before relationships.html --views optical` and inspect the captures. Diagnose the composition of `relationships.html#optical` using relevant installed Experience Skills. Render and inspect the view. Explain whether the allocation supports the proofing job and recommend only a justified correction. Do not edit, replace the identity, or assume equal columns prove balance.

## Mode
review

## Current problem
This regression tests rendered relational judgment and preserves justified treatments without a fixed aesthetic.

## Expected skills
- composition-repair

## Key principles expected
- Judge perceived weight through contrast, area, edges, type, and useful value rather than equal column widths alone.
- Distinguish decorative sample value from the proofing action and explain whether the dominant surface earns attention.
- Offer a focused repair with surrounding consequences to verify; preserve a justified dark or asymmetric composition.

## Unacceptable recommendations
- Declaring balance correct solely because both columns have equal width.
- Mandating symmetry, a light theme, or an unrelated new visual direction.
