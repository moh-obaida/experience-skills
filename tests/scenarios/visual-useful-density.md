# Scenario: Preserve Necessary Expert Density

## Scenario
An invented fleet dispatch console has eighteen route rows and eight operational columns with filters, state, timing, load, communication, and assignment controls. Darkness and density support shift work.
All scenes are invented in `visual-relationships.html`; `dense` is the target view.

## Prompt
Render the target view with `node .benchmark/render.mjs before relationships.html --views dense` and inspect the captures. Critically review `relationships.html#dense` for hierarchy and useful density. Render and inspect it, including its filters and assignment action. Dispatchers need the operational fields. Prioritize only observed material issues; do not edit or simplify solely to make it sparse.

## Mode
review

## Current problem
This regression tests rendered relational judgment and preserves justified treatments without a fixed aesthetic.

## Expected skills
- critical-review

## Key principles expected
- Distinguish useful operational information/action density from decorative visual density.
- Evaluate scannability, grouping, exceptions, and task priority while preserving required controls and valid dark surfaces.
- Prioritize material job consequences over cosmetic preferences; no-change is valid and routing remains selective.

## Unacceptable recommendations
- Removing needed columns or hiding frequent controls solely because the screen is dense.
- Replacing the dark professional console with a sparse marketing layout.
