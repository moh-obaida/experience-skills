# Observations: Productivity, Creative, and AI Products

Dated observations of real, public product surfaces made for Experience Skills. Each bullet has a
stable ID that precedent modules cite. Observations describe what was seen; interpretation lives in
the precedent modules (`shared/precedent/`) and the design-intelligence library.

**Method codes:** R = the live page was opened in a browser and looked at (desktop viewport about
800×600 CSS px unless noted; mobile at 375×812); T = page text or documentation read; R+T = both.
Regional versions differ; the region is noted where it affected what was seen. Sites change; treat
every observation as true on its date only. No screenshots are stored in this repository.

## Slack — homepage (https://slack.com/) — R, 2026-09-24
- SL1 Centered headline, two actions (filled "Get started", outlined "Find your plan"), a monochrome customer logo strip, then a framed product screenshot: the conventional SaaS landing sequence, executed cleanly with the brand aubergine as the single action color.
- SL2 The product screenshot shows real UI (channels, a bot conversation) rather than abstract art.

## Canva — homepage (https://www.canva.com/) — R, 2026-09-24
- CA1 A question headline ("What will you design today?") with one action ("Start designing") on a violet-to-blue gradient field with floating 3D sticker-like objects.
- CA2 The gradient and floating objects are the brand's playful creation world; the action itself is a single plain button.
- CA3 Cookie banner offers "Accept all cookies" and "Manage cookies" (no one-click reject).

## Webflow — homepage (https://webflow.com/) — R, 2026-09-24
- WF1 Left-aligned, very large two-line headline with generous right-side space at the top; below, a strip of product capability tiles with real UI crops.
- WF2 Cookie consent gives "Reject all" and "Accept all" equal-sized buttons.

## ChatGPT — logged-out start (https://chatgpt.com/) — R, 2026-09-24
- CG1 The product works before sign-in: the first viewport is the composer itself (attach, voice, send) under a one-line prompt ("Where should we begin?"). Value before commitment.
- CG2 A centered layout with large empty space is appropriate here: the single input is the entire task (FOCUSED archetype) and the conversation will fill the space. Centering frames the only thing that matters.
- CG3 One suggestion chip ("What can you do?") rather than a wall of example prompts; the sidebar explains what signing in adds ("responses tailored to you") instead of blocking.

## Claude — sign-in (https://claude.ai/login) — R, 2026-09-24
- CL1 A centered sign-in panel on a warm off-white field: serif display headline, SSO buttons first (Google, Apple), then email, one dark primary button; "Download desktop app" as a separate secondary action below.
- CL2 Identity comes from typography (a serif headline), a warm neutral palette, and the logo glyph rather than from an illustrated environment: a restrained identity budget for a focused task. Centered, but the type and color make it recognizable.

## Gmail — Undo Send (https://support.google.com/mail/answer/2819488) — Documentation (T), 2026-09-24
- GM1 After sending, "Message sent" appears with "Undo" in the corner; the cancellation window is user-configurable (5, 10, 20, or 30 seconds). A reversible delay replaces a pre-send confirmation.

## Notion — editing basics (https://www.notion.com/help/writing-and-editing-basics) — Documentation (T), 2026-09-24
- NO1 Typing "/" opens a menu of block types and actions at the cursor: the command surface lives where the user is typing.
- NO2 Markdown shortcuts at line start (# heading, [] checkbox, * bullet) give experts direct entry while menus serve beginners.
- NO3 A hover handle (⋮⋮) on each block is both a drag handle and an action menu (duplicate, delete, color, "Turn into"); "Turn into" converts a block's type in place.

## Framer — homepage (https://www.framer.com/) — R, 2026-09-24
- FR1 On a black canvas, the hero's focal object is the product's own AI prompt composer (glowing outline, "New Chat" selector, model picker) rather than an illustration: the input users will actually use is presented as the centerpiece.
- FR2 Left-aligned headline, two actions ("Get started for free", "Download app").

## Figma — homepage (https://www.figma.com/) — R, 2026-09-24
- FG1 A very large stacked typographic headline ("The full-stack creative canvas") with a single "Get started for free" action; a release-notes banner at the bottom edge.

## Notion — homepage (https://www.notion.com/) — R, 2026-09-24
- NT1 Large headline with one word set inside an animated pill-shaped chip; two actions; a real product screenshot; customer logo strip directly below.
